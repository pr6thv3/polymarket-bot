# Governance

The project is maintained as a safety-first open-source research tool.

## Maintainer responsibilities

- Keep the public README truthful.
- Require tests and source-contract validation for changes.
- Review source-contract promotions manually.
- Review mapping promotions manually.
- Reject unsupported profitability or live-readiness claims.

## Decision policy

Changes that affect these areas require maintainer review:

- source-contract versions;
- approved mapping catalog entries;
- fee/reward economics;
- strategy proof gates;
- live-capable code paths;
- security posture.

## Live trading policy

Live trading is currently `NO-GO`. A future live canary would require:

- legal/compliance clearance;
- positive paper evidence;
- explicit maintainer and user approval;
- isolated credentials;
- documented kill switch and rollback plan.
